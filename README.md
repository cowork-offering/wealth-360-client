# Wealth 360 · a private screening

The client screening page for Wealth 360: a servicing desk for a wealth manager, where agents do
the routine work, Salesforce keeps the rules and the record, and a named person makes every
decision that matters. Proof of concept, fictional clients, built in a Salesforce sandbox.

Entry is by passcode, which is on the invitation. The page carries the 90-second film in the
hero and the seven-minute walkthrough after chapter 07.
